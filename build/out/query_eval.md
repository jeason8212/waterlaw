# 查询集检索基线（规则 v0 + 三条可废止规则，全批次）

排序 = bigram-IDF 覆盖率 × 位阶权重 × R-a 流域降权 / R-b 特别法优先 / R-c 援引穿透（规则定义见 `s4_reason.find_law` docstring）。Top-5，命中任一金标条文即算对。
共 **60** 个查询（批次：批次1、批次2、批次3）。两种输入设定：
- **conduct**：查询串 = `regulated_conduct`，不含流域元信息（最难设定，诚实下界）；
- **full**：查询串仍为 `regulated_conduct`，但流域字段经 `basin_hint` 参数独立传入（元信息不进文本，避免稀释事由词判别力）。两设定的差值 = 流域元信息对可废止规则的贡献。

## 读法

- conduct 设定的数字是**诚实下界**：查询串不含流域信息时，R-a/R-b/R-c 多数被门控关闭（按可废止逻辑「不知道管辖事实就不用规则」），这正是设计意图；
- full − conduct 差值 = 流域元信息的边际贡献，论文里应单独成一列，以分离「信息量」与「表示层」的贡献；
- 条级显著高于款级，差值即「找对法条但找错款」的比例——支撑论文的**表示粒度**主张；
- 比 P@5 更重要的是 **flip accuracy**：能找到相关条文却分不清新旧，是表示层缺陷；
- 负对照（Q20/Q25/Q34/Q36/Q40）若 ❌，说明系统因 B1 新增援引/同构边而错误改判，这是论文必须报告的假阳性类型；
- 废止法引用率若为 0，是**表示层**的贡献，与检索质量无关。
